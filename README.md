# FINOVA-AI

> An agentic AI financial assistant that guides citizens on investments and loans, and helps banks assess loan eligibility.

## Problem
Most people in India struggle to decide where to invest their money (SIP, lump sum or SWP) and
which bank loan suits them. Loan offers from banks like SBI and Indian Bank are scattered across
different places, eligibility criteria are unclear,and banks spend significant effort manually
checking whether a citizen qualifies for a loan.

## Solution
FINOVA-AI is an AI agent that gives personalised investment guidance, compares loan options from
different banks, and checks loan eligibility. It also works as a management system for banks,
helping them decide whether a customer is eligible and what loan amount they can receive.

## Modules

### 1. Loan Processing and Eligibility
- Checks whether a citizen is eligible for a loan
- Explains the eligibility criteria and the possible loan amount
- Compares loan options from banks such as SBI and Indian Bank
- Recommends which loan suits the user best

### 2. Investment Advisor
- Guides users on investing through SIP, lump sum and SWP
- Shows the return types and expected return amounts
- Helps users choose where to invest based on their goals

### 3. Bank Management System
- Lets banks manage loan applications in one place
- Assesses citizen eligibility and loan amount
- Streamlines the loan decision workflow

## Agentic Workflow
User Input → AI Agent → Analysis of financial profile → Eligibility check and investment/loan comparison → Personalised recommendation → Final Result

## Key Features
- Loan eligibility check with criteria and loan amount
- Multi-bank loan comparison and recommendation
- SIP, lump sum and SWP investment guidance with return estimates
- Bank-side management system for loan processing
- Single platform combining loans, investments and bank operations
